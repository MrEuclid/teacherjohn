You need to use three (x,y) values from the table.
The easiest to work with are x = -1, x = 0 and x = 1.
You then put the values into $y = ax^2 + bx + c $ to get three equations.
Solving those equations will give you the values of a,b and c.
Example The (x,y) values are (-1,-2) , (0,-5) and (1-4)
$ a \times (-1)^2 + b \times -1 + c = -2 $
$ a \times (0)^2 + b \times 0 + c = -5 $
$ a \times (1)^2 + b \times 1 + c = - -4 $
The three equations are
I a -b + c = -2
II c = -5
III a + b + c = -4
Putting c = -5 into I and II gives us
a - b - 5 = -2 or a -b = 3
a + b + -5 = -4 or a + b = 1
a - b = 3 and a + b = 1
So a = 2 and b = -1 and c = -5
The equations is $ y = 2x^2 -x - 5$
