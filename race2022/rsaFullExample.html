The RSA Algorithm

This lesson tells you how to use the RSA method for cryptography (secret writing).

Prime numbers

First, you need four different prime numbers: p,q,e and d.

Choose p and q

p = 5
q = 23

Multiply them together

n = $ 5 \times 23 = 115 $

Calculate $ \phi $

$ \phi = (5 -1) \times (23-1) $
$ \phi = 4 \times 22 = 88 $

The numbers n and $ \phi $ are used to make the keys.

Make the public key, e

You need two numbers, e and d. The public key is e, anyone can see this and they use it to code messages that they send to you.
To read those messages you need to use d, which is your secret key.

Making e

  • e can be a small prime number (3,5,7,11,..)
  • e must be less than $ \phi $
  • When $ \phi $ is divided by e, the remainder must be greater then 0.

Try e = 3. $ \phi \div e = 22 \div 3 $ = 7 + remainder 1.

We can use e = 3.

You could not use e = 11 because $ \phi \div e = 88 \div 11 $ = 8 + remainder 0

Make the private key, d

Making d can be difficult. But for small numbers this method can be used.

You need to find a number so that $ e \times d $ has a remainder of 1 when divided by $ \phi $
3 $ \times d \div 88 $ has a remainder of 1

  1. Divide $ \phi $ by e
    88 $ \div 3 $ = 29 + 1 remainder
  2. add 1 to 29 and see if 30 is an answer
  3. 3 $ \times 30 \div 88 = 90 \div 88 = $ 1 + 2 remainder
  4. d = 30 is NOT an answer
  5. Try 30 + 29 = 59
  6. 3 $ \times 59 \div 88 = 177 \div 88 $
  7. 177 $ \div 88 = 2 + 1 $ remainder.
  8. d = 59 IS an answer

Now we have n = 115, e = 3 and d = 59 - you are ready to start sending messages!

Coding and Decoding a Message

We will start with a message in words and then change it into the number codes that are used by computers. A = 65, B = 66, Z = Z = 90. A space has a code of 32.

To send the message HELLO change it into 6 number codes H = 72, E = 69, L = 76, O =79.

Now use this formula C(i) = $ m(i)^e $ mod n,
m(i) is the number code - m(1) = 72, m(2) = 69, m(3) = 78, m(4) = 76 and m(5) =79.

C(1) = $ 72 ^ 3 $ mod 115

When using modulo arithmetic you only use the remainder from each calculation, it works like this:

  • $ 72^1 \div 115 = 72 \div 115 = 0 + 72 $ remainder
  • $ 72^1 $ mod 115 = 72
  • $ 72^2 \div 115 = 5184 $ \div 115 = 45 + 9 remainder
  • $ 72^3 mod 115 = (72^2 \times 72^1) mod 115 = (72 \times 9) $ mod 115
  • $ 72^3 $ mod 115 = 648 mod 115 = 73

The letter H = 72 and 72 is sent as 73

Using the same method, E = 69 and 69 is sent as 69, L = 76 and 76 is sent as 21, O = 79 and 79 is sent as 34.

HELLO -> 73 69 76 76 79 and is sent as 72,69,62,62,34

Receiving the message

The person receiving the message gets these numbers (72,69,62,62,34). If they try to read them using computer codes without decoding they will make OE>>" which doesn't make any sense.

Decoding the message

To decode the message they must use this formula P(i) = $ C(i)^d $ mod n $ = C(i)^59 $ mod 115

  1. P(1) = $73^59 $ mod 115
  2. P(2) = $69^59 $ mod 115
  3. P(3) = $62^59 $ mod 115
  4. P(4) = $62^59 $ mod 115
  5. P(5) = $34^59 $ mod 115
They are BIG numbers but with modulo we only need to use the remainders.

$ 72^59 $ mod 115 is calculated like this

  • $ 73^1 $ mod 115 = 73
  • $ 73^2 $ mod 115 = 73 x 73 mod 115 = 39
  • $73^4 $ mod 115 = $ 73^2 \times 73^2 $ mod 115 = 39 x 39 mod 115 = 26
  • $73^8 $ mod 115 = $ 73^4 \times 73^4 $ mod 115 = 26 x 26 mod 115 = 676 mod 115 = 101
  • $73^16 $ mod 115 = $ 73^8 \times 73^8 $ mod 115 = 101 x 101 mod 115 = 10201 mod 115 = 81
  • $73^32 $ mod 115 = $ 73^16 \times 73^16 $ mod 115 = 81 x 81 mod 115 = 6561 mod 115 = 6

59 = 32 + 16 + 8 + 2 + 1, so $73^59 mod 115 = $73^(32+16+8+2+1) $ mod 115 = 6 x 81 x 101 x 39 x 73 mod 115
= (6 x 81) mod 115 x (101 x 39) mod 115 x 73 = 26 x 29 x 73 mod 115 = 72

And 72 is the computer code for H - the message can now be decoded

The other answers can be checked by using tonline calculator.
